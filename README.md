# 📱 Kotlin Android Learning Journey

Welcome to my Kotlin Android journey! This README will track my learning progress and projects using [Jetpack Compose](https://developer.android.com/jetpack/compose) and the Android SDK. I aim to build at least 20 Android apps to gain hands-on experience and confidence in mobile development using Kotlin.

---

## ✅ Learning Milestones

### 📘 Fundamentals

- [ ] [Learn Kotlin syntax (variables, control flow, functions, OOP)](https://kotlinlang.org/docs/basic-syntax.html)
- [ ] [Understand Android project structure](https://developer.android.com/studio/projects)
- [ ] [Learn Jetpack Compose basics](https://developer.android.com/jetpack/compose/tutorial)

- [ ] [Understand Intents and Navigation](https://developer.android.com/guide/components/intents-filters)

- [ ] [Understand Permissions and Manifest](https://developer.android.com/training/permissions/requesting)

## 🛠️ Project-Based Learning

> Each project is a learning step. Projects increase in complexity to help me gradually explore more of the Android SDK, Jetpack Compose, and best practices.

### 🎯 Beginner Apps

- [ ] ✅ **01. Todo App** – Add, edit, and delete tasks. Learn ViewModel and State in Compose.
- [ ] **02. Calculator App** – Basic calculator UI and logic.
- [ ] **03. Notes App** – Persist notes using Room DB.
- [ ] **04. Tip Calculator** – Simple UI to calculate tips.
- [ ] **05. Login/Register UI** – Authentication screens with form validation.
- [ ] **06. Countdown Timer** – Custom countdown timer with Compose animations.
- [ ] **07. Quiz App** – Load questions from a JSON and track score.
- [ ] [**08. Weather App** – Use OpenWeather API with Retrofit](https://openweathermap.org/api)
- [ ] **09. Stopwatch App** – Chronometer using Coroutines and state.
- [ ] **10. Flashlight App** – Toggle flashlight using device hardware.

### 🧠 Intermediate Apps

- [ ] **11. Expense Tracker** – Add daily expenses, categorize, and use Room.
- [ ] **12. Habit Tracker** – Track habits with calendar view.
- [ ] **13. Contacts App** – CRUD contacts using SQLite or Room.
- [ ] [**14. Image Gallery App** – Load images from storage, use permissions](https://developer.android.com/training/data-storage/shared/media)
- [ ] **15. Music Player** – Play local MP3s using MediaPlayer API.
- [ ] [**16. News Reader** – Load latest news using Retrofit + LazyColumn](https://newsapi.org/)
- [ ] **17. Chat UI Clone** – WhatsApp or Messenger UI clone.
- [ ] [**18. Firebase Auth App** – Sign in with email and Google via Firebase](https://firebase.google.com/docs/auth/android/google-signin)
- [ ] [**19. Barcode/QR Scanner** – Use CameraX and ML Kit](https://developers.google.com/ml-kit/vision/barcode-scanning/android)
- [ ] [**20. Social Media Feed** – Post, like, and scroll using fake API data](https://jsonplaceholder.typicode.com/)
